# 커밋별 실행 화면 캡처 계획

순번 태그(`001`~`079`)를 하나씩 체크아웃해서 앱을 실행하고, 그 커밋에서 **눈에 보이는 실행 변화**만 캡처합니다.

- 표기
  - **B** = 브라우저 화면
  - **H** = H2 콘솔(SQL 실행 결과)
- 화면 변화가 없는 단계(설정, 리팩터링, 테스트만 추가, 문서)는 건너뜁니다.

## 진행 방식
1. 임시 worktree에서 `git checkout <태그>` → 개발 DB 삭제(빈 DB에서 시작) → `bootRun`(포트 8092)
2. ego lite로 화면을 열고, 필요하면 조작(로그인, 폼 입력 등)한 뒤 캡처합니다.
   - 창 크기는 1280×800으로 고정합니다.
3. H2 콘솔은 `/h2-console`에 접속해 SQL을 실행한 결과를 캡처합니다.
   - 접속 주소: `jdbc:h2:./db_dev;MODE=MySQL`
4. 결과 저장
   - 이미지: `docs/captures/<순번>-<기능태그>-<번호>.jpg`
   - 목록: `docs/CAPTURES.md`(순번, 태그, 설명, 이미지)
   - 커밋 하나로 추가합니다(`041-01`).
5. 로그인이 필요한 단계는 개발용 계정 `user1`(BaseInitData)을 씁니다.
   - 078(구글 로그인)은 앞서 실제 구글 로그인으로 확인한 화면을 재사용합니다.
